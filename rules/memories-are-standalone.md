# Memories are standalone

Every memory must be fully understandable alone. Add a `[[link]]` only when
the point genuinely cannot be made without it. This overrides the harness
default to link liberally.

**Why:** links between memories age into noise: "Related:" pointers restate
nothing, citations of globally-applying rules add nothing, and provenance
links into status snapshots dangle once the snapshot is deleted.

**How to apply:** inline the fact instead of pointing at it: the URL, the
date, the name. Never cite a rule because it also applies; global rules apply
unreferenced. State the mechanism, never the attribution: a memory's why
carries why the rule holds, not who decided it or the incident that prompted
it. Provenance is inline text with a date, never a link.
